## 6. Grading System
Grades are based only on scholastic performance.

**Formulas (as written on the policy page):**
```
PG = 0.50 PE + 0.50 CSP
MG = 1/3 PG + 2/3 (0.50 ME + 0.50 CSM)
FG = 1/3 MG + 2/3 (0.50 FE + 0.50 CSF)
```

The page does not define the abbreviations. The usual reading, which you should confirm with the adviser:

| Symbol | Likely meaning |
|---|---|
| PG, MG, FG | Prelim grade, Midterm grade, Final grade |
| PE, ME, FE | Prelim exam, Midterm exam, Final exam |
| CSP, CSM, CSF | Class standing for Prelim, Midterm, Final |

**Class standing weights:**

| Component | Weight |
|---|---|
| Long and short quizzes | 40% |
| Graded recitation or report | 10% |
| Assignments or homework | 10% |
| Term paper or research work | 40% |
| **Total class standing** | **100%** |

Projects are not part of class standing. They are usually included in the exam grade for lecture and laboratory courses.

### Worked Example (hypothetical scores)
| Period | Exam | Class standing |
|---|---|---|
| Prelim | PE = 80 | CSP = 90 |
| Midterm | ME = 75 | CSM = 85 |
| Final | FE = 90 | CSF = 90 |

1. **PG** = 0.50(80) + 0.50(90) = 40 + 45 = **85.00**
2. **MG** = 1/3(85.00) + 2/3(0.50(75) + 0.50(85)) = 28.33 + 2/3(80) = 28.33 + 53.33 = **81.67**
3. **FG** = 1/3(81.67) + 2/3(0.50(90) + 0.50(90)) = 27.22 + 2/3(90) = 27.22 + 60.00 = **87.22**

The Final grade weights the Final period at two-thirds of the total, so the Final exam and class standing matter most.

## 10. Academic Integrity
Submitted work must be original, properly documented, and done as instructed. These count as academic dishonesty:
- Cheating and plagiarism
- Copying source code or another student's design
- Falsifying laboratory results
- Submitting downloaded or AI-generated work without permission or acknowledgment
- Misrepresenting group contributions
- Reusing earlier outputs without approval
