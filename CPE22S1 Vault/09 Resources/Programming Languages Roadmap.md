# Programming Languages Roadmap

| Priority | Language | Courses | Why |
|---|---|---|---|
| 1 | C++ | CPE 111, MATH 020, CPE 015A | Base language for most programming work |
| 2 | SQL | [[CPE 011A Index\|CPE 011A]] | Queries, joins, database design |
| 3 | Python | MATH 020, CPE 015A, CPE 111, CPE 302, CPE 18A | Fast checking of numerical and optimization work |
| 4 | Embedded C | [[CPE 111 Index\|CPE 111]] | Microcontroller code |
| 5 | Assembly | [[CPE 021A Index\|CPE 021A]] | Instruction sets, registers, memory |
| 6 | Verilog or VHDL | [[CPE 013 Index\|CPE 013]] | Only if the course requires it |
| 7 | Cisco IOS CLI, Linux shell | [[CPE 302 Index\|CPE 302]] | Router and switch lab configuration |
